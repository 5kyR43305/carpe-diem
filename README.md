# Game Quiz

게임에 대해 얼마나 알고 계신가요? 기억만으로 이름을 전부 맞혀 보는 게임 퀴즈 사이트입니다.

**▶ 플레이하기: https://5kyr43305.github.io/game-quiz/**

*How well do you know your games? Name every champion, skin line and skin collection from memory. Available in Korean and English.*

## 퀴즈 목록

| 게임 | 퀴즈 | 내용 |
|---|---|---|
| 리그 오브 레전드 | 챔피언 이름 맞추기 | 모든 챔피언의 이름을 맞혀 보세요 |
| 리그 오브 레전드 | 챔피언 칭호 맞추기 | 무작위로 나오는 칭호를 하나씩 보고 챔피언을 맞혀 보세요 (예: 구미호 → 아리) |
| 리그 오브 레전드 | 스킨 세트 이름 맞추기 | 모든 스킨 세트(스킨 라인)의 이름을 맞혀 보세요 |
| 발로란트 | 스킨 컬렉션 이름 맞추기 | 모든 무기 스킨 컬렉션의 이름을 맞혀 보세요 |

### 도구

| 게임 | 도구 | 내용 |
|---|---|---|
| 발로란트 | 요원 랜덤 뽑기 | 2~5명, 역할군(타격대·전략가·감시자·척후대)별 인원을 정해 요원을 랜덤으로 뽑습니다 |
| 리그 오브 레전드 | 챔피언 랜덤 뽑기 | 2~5명, 주 역할군(암살자·전사·원거리·마법사·탱커·서포터)별 인원을 정해 챔피언을 뽑습니다. 포지션 추첨(포지션만 다시 뽑기 가능)도 가능 |

두 뽑기 모두 인원 수만큼 참가자 이름을 적을 수 있고, 뽑을 때 참가자와 결과가 무작위로 짝지어집니다.

퀴즈 항목은 추후 업데이트됩니다.

## 플레이 방법

- 이름을 입력하고 **Enter** 또는 **정답** 버튼을 누르면 등록됩니다.
- 선택한 언어의 **공식 이름**으로 입력해야 정답입니다. 띄어쓰기·대소문자·문장부호는 구분하지 않습니다.
- 첫 정답을 맞히면 타이머가 시작됩니다.
- 오른쪽 위에서 **한국어 / English**를 바꿀 수 있습니다. 게임 중에 언어를 바꾸면 진행 내용이 초기화됩니다.

### 힌트
- 첫 정답 후 **3분마다** 힌트를 받을 수 있습니다.
- 힌트가 준비되면 **초성** 또는 **실루엣** 중 하나를 골라 볼 수 있습니다.
  - 이름 맞추기 퀴즈: 아직 못 맞힌 항목 하나의 번호와 함께 공개됩니다.
  - 칭호 퀴즈: 지금 화면에 나온 칭호의 챔피언에 대해 공개됩니다.
- 힌트로 나온 항목을 맞혀야 다음 힌트 타이머가 시작됩니다.
- 진행도가 **90% 이상**이면 힌트를 사용할 수 없습니다.

### 종료와 포기
- **종료**: 지금까지의 결과(맞힌 수 / 전체 수, 걸린 시간)를 보고 게임을 끝냅니다. 못 맞힌 정답도 함께 공개됩니다.
- **포기**: 진행 내용과 타이머를 초기화하고 처음부터 다시 시작합니다.

### 최고 기록
- 퀴즈마다 최고 기록(맞힌 수, 걸린 시간)이 저장되어 화면에 표시됩니다. 더 많이 맞힐수록, 같은 수라면 더 빠를수록 좋은 기록입니다.
- 기록은 사용 중인 브라우저에만 저장됩니다.

## 데이터
